# 墨矩 MoJu

墨矩是一个 Android AI 工具集合应用，目标是把聊天助手、校园课表、记事工具和后续更多实用功能整合到一个移动端工作台里。

这个仓库只用于公开发布 APK 安装包。源码仓库保持私有，不在这里开放。

## 下载

最新版 APK 在 Releases 页面下载：

https://github.com/Andonis75/MoJu-Releases/releases/latest

当前公开版本：

- v1.1.0
- Android 8.0 及以上
- 安装包：`app-release.apk`

## 已包含功能

- AI 聊天助手
- 本地联网搜索开关
- 助手预设与系统提示词配置
- 课程表
- 海南师范大学教务课表导入
- 课程周次、单双周、教室信息解析
- 记事工具
- 图片/文件附件入口
- 功能中心入口

## 使用说明

1. 在 Releases 页面下载 `app-release.apk`。
2. 安装时如果系统提示未知来源，需要允许浏览器或文件管理器安装 APK。
3. 首次使用 AI 功能时，在应用设置中填写自己的模型接口、模型名和 API Key。
4. 课程表导入功能需要用户自己登录教务系统，应用不会保存教务账号密码。
